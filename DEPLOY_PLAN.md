# ARAN.co – Deployment plan

A short, ordered plan to take ARAN.co from your laptop to a live URL.
(`DEPLOYMENT.md` is the long reference checklist for payments, SMS, legal and operations; this file is the step-by-step plan.)

## 1. Target setup

| Piece | Service | Plan | URL |
|---|---|---|---|
| Storefront + admin + rider app (React PWA) | **Vercel** (or Cloudflare Pages) | Free / Pro | `https://aran.co` |
| API + Socket.IO (Node) | **Render** web service (`render.yaml`) | **Starter $7/mo – must not sleep** | `https://api.aran.co` |
| Database | **MongoDB Atlas** | M0 free for staging, **M10 for production** (backups) | – |
| Images | **Cloudinary** | Free | – |
| DNS / CDN | **Cloudflare** | Free | – |

Use subdomains of **one** domain (`aran.co` + `api.aran.co`). The login cookie is then same-site and safe. Optional: `admin.aran.co` as a second Vercel project with `VITE_APP_MODE=admin`.

> The Cloudflare *quick tunnel* you use for demos is temporary. Never use it for real customers.

## 2. Phases

### Phase 0 – Before you touch hosting (1 day)
- [ ] Buy the domain, put DNS on Cloudflare.
- [ ] Push the code to a **private** GitHub repo (the `.gitignore` is fixed, so `.env` is not committed – check with `git status` first).
- [ ] **Rotate the Atlas database password** you used in development, and create a *new* DB user for production.
- [ ] Generate 3 secrets: `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"` (run 3×).
- [ ] Start **DLT / SMS registration** and **Razorpay KYC** now – they take 1–7 days and block OTP login and online payments.

### Phase 1 – Staging (half a day)
1. **Atlas:** create cluster, DB user, network access (allow Render's outbound IPs, or `0.0.0.0/0` for staging only). Copy the `mongodb+srv://…/aran` string.
2. **Render → New → Blueprint** from the repo (uses `render.yaml`, root `backend`). Fill in:
   - `MONGODB_URI`
   - `CLIENT_URL` = `https://staging.aran.co` (or the Vercel preview URL)
   - `CLIENT_ORIGINS` = same (comma-separate extra origins)
   - `SEED_OWNER_EMAIL`, `SEED_OWNER_PASSWORD`, and `SEED_ON_START=1` (first boot only)
   - `CLOUDINARY_*` (optional for staging)
   - JWT secrets and `SETTINGS_ENCRYPTION_KEY` are auto-generated by the blueprint – **save `SETTINGS_ENCRYPTION_KEY`; changing it later breaks stored gateway/SMS secrets.**
3. Check `https://<render-url>/api/v1/health` returns OK.
4. **Vercel → New project**, root `frontend`, build `npm run build`, output `dist`. Env: `VITE_API_URL=https://<render-url>`. (`vercel.json` already rewrites all routes to the SPA.)
5. Open the site, sign in at `/admin/login`, **change the owner password**.

### Phase 2 – Configure the business (1 day, in the admin panel)
- Settings → brand name, **phone, email, address, opening hours, social links** (these replace the placeholder contact data in the footer and Contact page).
- Settings → delivery radius / PIN codes / fee, tax, pickup slots.
- Categories / Products / Homepage hero: real prices, photos, availability.
- Settings → SMS & OTP (MSG91 key + DLT template) → *Send test*.
- Settings → Payment gateway (Razorpay **test** keys first) → *Test connection*; add the webhook URL shown there in Razorpay.
- Delivery → add riders.
- Replace the placeholder content in `frontend/src/config/siteContent.js` (FAQ, support topics, WhatsApp number, maps link) and have the Terms / Privacy / Refund pages reviewed by a lawyer.

### Phase 3 – Full test on staging (half a day)
- [ ] Place a test order (online + cash on delivery + pickup), accept in admin, assign rider, rider delivers with the handover code, then refund it.
- [ ] Test on a real phone: install the PWA, OTP login, live tracking.
- [ ] `npm test` in `backend` and `frontend`; `npm run test:e2e`.
- [ ] Lighthouse on the staging URL.

### Phase 4 – Go live (2 hours)
1. Atlas: upgrade to **M10**, enable backups, restrict network access to Render's IPs.
2. Render: set `NODE_ENV=production` (blueprint does), real `CLIENT_URL` / `CLIENT_ORIGINS` = `https://aran.co`, remove `SEED_ON_START` and `SEED_OWNER_PASSWORD`. Add custom domain `api.aran.co`.
3. Vercel: set `VITE_API_URL=https://api.aran.co`; add domain `aran.co`; redeploy.
4. Cloudflare DNS: `aran.co` → Vercel, `api.aran.co` → Render. Keep HTTPS on.
5. Switch Razorpay to **live** keys in Admin → Payment gateway; update the webhook.
6. Repeat the Phase 3 order test with ₹1–10 on live, then refund.
7. Add uptime monitor on `https://api.aran.co/api/v1/health` (UptimeRobot) and Sentry if you want error alerts.

### Phase 5 – After launch
- Daily: check admin notifications (low stock, failed payments). Weekly: review reviews and the audit log.
- Atlas backup restore test once; `npm audit` monthly.

## 3. Environment variables (cheat sheet)

**API (Render)** – required: `NODE_ENV=production`, `MONGODB_URI`, `JWT_ACCESS_SECRET`, `JWT_REFRESH_SECRET`, `SETTINGS_ENCRYPTION_KEY`, `CLIENT_URL`, `CLIENT_ORIGINS`.
First boot only: `SEED_ON_START=1`, `SEED_OWNER_EMAIL`, `SEED_OWNER_PASSWORD`.
Optional: `CLOUDINARY_*`, `SMTP_*`, `VAPID_*`, `WHATSAPP_*`, `BUSINESS_TZ`.

**Frontend (Vercel)** – `VITE_API_URL` (API origin). Optional: `VITE_APP_MODE` (`store` / `admin`), `VITE_MAP_TILE_URL`.

## 4. Rollback and safety
- **Frontend:** Vercel → Deployments → *Promote* the previous build (instant).
- **API:** Render → Deploys → *Rollback*.
- **Database:** Atlas point-in-time restore (M10+).
- Never edit production data by hand without a backup; keep `SETTINGS_ENCRYPTION_KEY` in a password manager.

## 5. Common problems
| Symptom | Cause / fix |
|---|---|
| "CORS origin not allowed" | The site's exact origin is missing from `CLIENT_ORIGINS` (include `https://`, no trailing slash). |
| Logged out on refresh | Frontend and API are on unrelated domains, or the site is not on HTTPS. Use subdomains of one domain. |
| First request takes ~30 s | Render is on the free plan and sleeps → use Starter. |
| Live tracking / alerts not updating | The API host must support WebSockets and must not sleep. |
| OTP not delivered | DLT template / sender ID not approved yet, or MSG91 key missing. |
| Old version still showing | PWA cache: hard-refresh, or accept the "update available" prompt. |

## 6. Rough cost
Render $7 + Atlas M10 ~$57 + domain ~₹1,000/yr + Vercel / Cloudflare / Cloudinary free tiers ≈ **$65/month** at launch (use Atlas M0 for staging only). SMS ~₹0.2 per OTP; Razorpay ~2% per payment.
